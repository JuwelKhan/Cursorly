Give your cursor
some personality.

Cursorly is a tiny library for custom cursor effects. Rings that wrap your buttons, blobs that invert the page, neon trails, sparkles, a torch-like spotlight and magnetic links — mix any of them in one line.

Magnetic & sticky

04 — Get started

Two ways in.

index.html — no build step
<script src="https://cdn.jsdelivr.net/npm/cursorly@0.9/dist/cursorly.min.js"
        data-cursorly="classic"></script>
main.js — npm
import Cursorly from 'cursorly';

const cursor = new Cursorly({ preset: 'classic' });

cursor.on('enter', ({ target }) => console.log(target));
AttributeWhat it does
data-cursor="name"Sets a named state while hovering (style it per effect with states).
data-cursor-text="View"Shows a label inside the ring, blob or orbit.
data-cursor-color="#fff"Recolours the cursor inside this element.
data-cursor-magnetic="0.4"Pulls the element towards the pointer.
data-cursor-stickThe ring morphs around the element.
data-cursor-hideNative cursor inside this element.
